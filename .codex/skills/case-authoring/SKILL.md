# Case Authoring

Before working, read:

- `docs/specs/product-case-writing-rules.md`
- `docs/specs/portfolio-case-json-structure.md`
- `docs/specs/case-blocks-reference.md`

Use existing case content and user-provided material as evidence. Identify missing facts before drafting; label hypotheses and never invent users, research, constraints, causality, impact, or metrics.

Build the narrative as conclusion -> arguments -> evidence. Prepare the full case and `shortSummary` according to their separate contracts. Keep subtitle format, media-to-claim mapping, role, status, AI contribution, and limitations explicit. Treat Globus as a completed release-waiting status case.

Return a draft for approval before writing to `content/work/*.mdx`. Do not declare an unfinished case final without an explicit request.
