## Правило точки отсчета T0

На дату `08.09.2026`:

- все абсолютные показатели этого отчета являются значениями baseline;
- абсолютное изменение каждой метрики относительно baseline равно `0`;
- относительное изменение каждой метрики относительно baseline равно `0%`.

В следующих замерах изменение рассчитывается только для одной и той же метрики:

- абсолютное изменение: `новое значение - значение T0`;
- относительное изменение: `(новое значение - значение T0) / значение T0 × 100%`;
- если значение T0 равно нулю, относительное изменение не рассчитывается; фиксируются новое абсолютное значение и факт появления сигнала.

Сопоставимым считается замер с тем же счетчиком, длительностью периода, выборкой, фильтрами, составом целей и правилами расчета. Если условия изменились, отличие фиксируется рядом с результатом и не интерпретируется как чистое изменение поведения.

Точные дневные значения из этого PDF восстановить нельзя. Для сравнения по отдельным датам нужен CSV/XLSX-экспорт с датой и числовыми значениями.
